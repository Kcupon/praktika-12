# Архитектура АИС «АвиаПермь»

## Общая схема

```
 Пассажиры, менеджеры           Сервер (Ubuntu 22.04, Docker Compose)
 ┌──────────────────┐   HTTPS   ┌───────────┐   ┌───────────────────┐   ┌──────────────┐
 │ Веб-клиент React │──────────▶│   Nginx   │──▶│ aviaperm-backend  │──▶│ PostgreSQL 16│
 │ (SPA, TypeScript)│  TLS 1.3  │  (прокси) │   │ Spring Boot, :8080│   │ + Redis 7    │
 └──────────────────┘           └───────────┘   └─────────┬─────────┘   └──────────────┘
                                                          │ события
                                                          ▼
                                                ┌───────────────────┐
                                                │  aviaperm-notify  │──▶ push / SMS / email
                                                │    (RabbitMQ)     │
                                                └───────────────────┘
 Внешние системы: GDS «Сирена-Трэвел», Aviasales Partner API, платёжный шлюз, СБП
```

## Компоненты

| Компонент | Назначение |
|-----------|-----------|
| Веб-клиент (React 18, TypeScript) | Поиск рейсов, оформление брони, личный кабинет, панель менеджера |
| Nginx | Обратный прокси, шифрование TLS 1.3 |
| aviaperm-backend (Java 21, Spring Boot 3.3) | REST API, бизнес-логика, расчёт цены и возвратов |
| PostgreSQL 16 | Хранение данных (users, flights, bookings, tickets, payments и др.) |
| Redis 7 | Кеш результатов поиска рейсов |
| aviaperm-notify (RabbitMQ) | Очередь и рассылка уведомлений |

## Контуры

- **Разработка** — локальные стенды разработчиков, ветки feature/*;
- **Тестирование** — тестовый стенд, собирается только из помеченной версии (тег);
- **Продуктив** — рабочий сервер в дата-центре Tier III, обновляется по согласованному релизу.

## Интеграции

- GDS «Сирена-Трэвел» и Aviasales Partner API — поиск тарифов и бронирование;
- платёжный шлюз и СБП — оплата; данные карт токенизирует шлюз;
- SMS- и email-сервисы — уведомления пассажиров.
