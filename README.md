# Проект внедрения АИС «АвиаПермь»

## Назначение

Репозиторий содержит материалы проекта внедрения автоматизированной
информационной системы бронирования и продажи авиабилетов «АвиаПермь»
в туристическом агентстве ООО «Тревел Эйр Пермь». Система должна сократить
оформление брони с 40–90 минут до 3 минут и позволить клиентам покупать
билеты онлайн круглосуточно. Здесь хранятся требования, описание архитектуры,
настройки, тестовые сценарии и план проекта.

## Структура папок

```
project_IS/
├── docs/                    # проектная документация
│   ├── requirements.md      # требования к системе
│   └── architecture.md      # описание архитектуры
├── src/                     # код / конфигурации
│   └── config_settings.md   # параметры развёртывания и настройки
├── tests/                   # тестовые материалы
│   └── test_cases.md        # тестовые сценарии
├── management/              # управленческая информация
│   └── project_plan.md      # план-график и риски проекта
└── README.md                # описание проекта
```

## Как использовать

1. Клонировать репозиторий: `git clone https://github.com/Kcupon/praktika-12.git`.
2. Начать знакомство с `docs/requirements.md` и `management/project_plan.md`.
3. Каждую задачу вести в отдельной ветке, перед работой выполнять `git pull`,
   после — коммит с понятным сообщением и `git push`.
4. Тестировать по сценариям из `tests/test_cases.md` и указывать в протоколе
   тег сборки, на которой шла проверка.
