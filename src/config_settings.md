# Параметры развёртывания и настройки

## Сервисы Docker Compose

| Сервис | Образ / технология | Порт |
|--------|--------------------|------|
| nginx | Nginx, TLS 1.3 | 443 |
| aviaperm-backend | Java 21, Spring Boot 3.3 | 8080 |
| aviaperm-postgres | PostgreSQL 16, репликация WAL | 5432 |
| redis | Redis 7 | 6379 |
| aviaperm-notify | RabbitMQ | 5672 |

## Параметры приложения

| Параметр | Значение |
|----------|----------|
| Время удержания тарифа | 20 минут |
| Срок действия access-токена JWT | 20 минут |
| Срок действия refresh-токена | 30 суток (cookie HttpOnly, Secure) |
| Хеширование паролей | Argon2id |
| Блокировка входа | 15 минут после 5 неверных попыток |
| Комиссия агентства | 0–5% в зависимости от тарифного класса |

## Роли пользователей (RBAC)

- `Администратор` — учётные записи, аудит журналов;
- `Менеджер` — тарифы, бронь от имени клиента, возвраты, отчёты;
- `Оператор поддержки` — просмотр брони и тарифов;
- `Пассажир` — свои брони, оплата, заявка на возврат.
